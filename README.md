📊 Netflix Movies Data Analysis
This project involves exploring and analyzing a dataset of movies available on Netflix. Using Python's powerful data manipulation and visualization libraries, I cleaned, transformed, and visualized the dataset to extract key insights about Netflix movies, such as the most popular genres, movie performance categories, and yearly trends.

🛠️ Libraries Used
NumPy
Pandas
Matplotlib
Seaborn

Overall, This project involved:

Cleaning and transforming real-world movie data.
Deriving meaningful features such as Vote_Average categories.
Visualizing patterns in genres, movie quality, and popularity.
Identifying top and bottom-performing movies by different metrics.
